## REMOVED Requirements

### Requirement: By Other Hands works have no wishlist
**Reason**: Collectors hunt for Works by Others (Dark Tower comics, companion books) the same way they hunt for King works, so the wishlist now covers both kinds of work.
**Migration**: By Other Hands works show the same wishlist control as King works (see the wishlist capability's "Wishlist control on the book actions component"). No user data exists to migrate, because By Other Hands works never had a wishlist state.
